# 봇 수동 조종 · 테스트 키 (§20.3)

코드: `Bot/Brains/ManualKeyBrain.cs`, `Bot/BotPlayer.cs`, `Server/ServerTestScenarios.cs`

## 봇 수동 조종

| 키 | 동작 |
| --- | --- |
| Space | 자동(타이머) ↔ 수동 전환 |
| 1 ~ 8 | 해당 슬롯 시전 |
| Q / W / E | 조준 열 — **서버 카메라(Home 시점) 화면 기준** 좌 / 중 / 우 |
| ↑ / ↓ | 범위 공격 깊이 ±0.1 |
| ← / → | 봇 이동 (화면 기준) |

- **PC 서버 창**: 키를 그대로 누른다.
- **에디터 로컬 모드(LocalVsBot)**: 사람 키보드 입력과 겹치지 않도록 **Alt를 누른 채** 입력한다 (`BotConfig.RequireAltInLocalMode`).

## 테스트 시나리오 (개발 빌드 전용)

| 키 | 동작 |
| --- | --- |
| F1 / F2 | Home / Away 타워 즉시 파괴 |
| F3 / F4 | Home / Away 넥서스 즉시 파괴 (타워도 함께, 돌파 시작) |
| F5 / F6 | Home / Away HP 1 |
| F7 | 5분 강화 즉시 발동 |
| F8 | 양측 쿨타임 즉시 초기화 |
| F11 | DebugOverlay(FPS · 유닛 수 · 핑 · 경기 시간) 토글 |
| F12 | 서버 디버그 패널 토글 |

## 사람 플레이어 키보드 대체 입력 (§6.6, 에디터)

| 입력 | 동작 |
| --- | --- |
| 1 ~ 8 | 슬롯 바로 시전 (룬 생략). 조준 스킬은 마우스 위치로 2초 조준 후 시전 |
| 마우스 왼쪽 드래그 | 룬 그리기 (= 핀치 유지) |
| F | 주먹 (Armed / 자기 · 타워 · 전역 스킬은 즉시 시전) |
| G | 검지 포인팅 (Aiming 시작) |
| X / 마우스 오른쪽 | 손바닥 펴기 (취소) |
| A / D | 왼쪽 / 오른쪽 이동 |
