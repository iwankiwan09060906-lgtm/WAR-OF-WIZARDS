# VR 테스트 가이드 — Quest로 처음부터 끝까지

헤드셋 하나로 **로그인 → 덱 선택 → 경기 → 결과(전적 저장) → 로비 / 게임 종료**를 모두 해 보는 순서다.
전체 규칙은 [`GameFlow.md`](GameFlow.md), PC로 스킬만 시험할 때는 [`MANUAL_TODO.md`](../../MANUAL_TODO.md) §12.

---

## 1. 준비 (처음 한 번)

| # | 어디서 | 할 일 |
| --- | --- | --- |
| 1 | Quest | 설정 → 개발자 모드 켜기 (Meta Horizon 앱), **설정 → 동작 추적 → 손 추적 켜기** |
| 2 | PC | `Backend/open-firewall.bat` 을 관리자 권한으로 실행 (웹 백엔드 8080 포트 허용) |
| 3 | PC · Quest | **같은 Wi-Fi**에 연결 |
| 4 | Unity | (선택) Google 로그인을 쓰려면 `Assets/_Project/Backend/Resources/GoogleOAuth/device_client.json` 에 client_secret ([`MANUAL_TODO.md`](../../MANUAL_TODO.md) §11) |

## 2. 빌드 · 설치

1. PC에서 `Backend/run_server.bat` 실행 (로그인 · 덱 · 전적을 저장하는 웹 백엔드).
2. Unity 메뉴 **`Spellbound > Build > ★ Quest APK — VR 전체 흐름`** → `Builds/Quest/WarOfWizards_VR.apk`.
   - 빌드할 때 이 PC의 LAN 주소(`http://192.168.x.x:8080`)가 앱에 들어간다 — 헤드셋에서 주소를 칠 필요가 없다. Console에 `Quest 백엔드 주소: …` 로 찍힌다.
   - 경기는 **헤드셋 안에서 봇과** 한다 (PC 게임 서버 필요 없음). 랭킹전도 상대는 봇이지만 레이팅 · 전적은 서버에 저장된다.
3. Quest를 USB로 연결하고 설치: `adb install -r Builds/Quest/WarOfWizards_VR.apk` (또는 Meta Quest Developer Hub / SideQuest에 끌어 놓기).
4. Quest 앱 목록 → **알 수 없는 출처** → War of Wizards 실행.

## 3. 헤드셋 안에서 조작

| 하는 일 | 손 (핸드 트래킹) | 컨트롤러 |
| --- | --- | --- |
| 메뉴 가리키기 · 누르기 | 오른손 레이로 가리키고 **엄지 · 검지 집기** | 오른손 레이 + 검지 트리거 (또는 A) |
| 목록 스크롤 · 슬라이더 | 집은 채로 손을 움직이기 | 트리거를 누른 채 움직이기 |
| 글자 입력 | 입력칸을 누르면 아래에 **화면 키보드** (영문 · 숫자 · `@ . : / _ -`, 모두 지우기) | 같음 |
| 룬 그리기 → 시전 | 오른손 핀치로 그리기 → 주먹 → 검지로 2초 가리키기 | — (손으로 플레이) |
| 취소 · 이동 | 오른손 손바닥 펴기 · 왼손을 펴고 좌우로 휘두르기 | — |
| **경기 메뉴 (계속 · 기권)** | **왼손 손바닥을 얼굴 쪽으로 보이고 엄지 · 검지 집기** (메뉴 제스처) | 왼쪽 컨트롤러 **☰** 버튼 |

- 메뉴 판은 시작 직후 시선을 따라 정면에 선다. 고개를 크게 돌린 채 1.5초 있으면 다시 정면으로 온다.
- 경기 중에는 메뉴 레이가 꺼져 핀치가 룬 그리기로만 쓰인다.

## 5. 문제 해결

| 증상 | 원인 · 해결 |
| --- | --- |
| C01이 "서버 꺼짐" · 로그인 실패 | ① PC에서 `run_server.bat` 이 켜져 있는지 ② 같은 Wi-Fi인지 ③ `open-firewall.bat` ④ C01 **주소 변경**에 PC IP (IP만 쳐도 `http://…:8080` 이 붙는다, 비우고 저장하면 빌드 기본 주소) |
| 서버 없이 해 보고 싶다 | C01 **서버 없이 시작 (봇 연습)** — 봇 연습전만, 전적 저장 안 함 |
| 메뉴 판이 안 보임 | 고개를 돌려 1.5초 기다리기 (정면으로 다시 온다) |
| 손이 레이로 안 잡힘 | Quest 설정에서 손 추적 켜기, 손을 시야 안에 |
| Google 버튼이 "설정이 끝나지 않았습니다" | `device_client.json` 이 없다 (§1-4) |
| 랭킹전 · 친선전 카운트다운이 오래 걸림 | Fusion 빌드에서 PC 게임 서버를 찾는 중 — 25초 안에 못 찾으면 자동으로 로비, C11 **취소하고 로비로** 로 바로 나갈 수 있다 |

## 6. 사람 대 사람 (선택)

`Spellbound > Build > PC Server (Windows)` → `RunServer.bat`, Quest는 `Spellbound > Build > Quest APK (Fusion Client → PC server)`.
이 빌드에서는 **랭킹전 · 친선전만 PC 게임 서버**로 가고, 봇 연습전 · 스킬 테스트는 여전히 헤드셋 안에서 한다.
PC 서버 창은 경기가 시작되면 사이드뷰로 바뀐다 (`V` 시점 전환).
