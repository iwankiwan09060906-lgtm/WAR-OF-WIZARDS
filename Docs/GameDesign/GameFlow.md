# 게임 전체 진행 방식 — War of Wizards

접속부터 결과까지 한 판이 어떻게 흘러가는지 정리한 문서. 화면 번호(C01~C13)는 `UnityClient/Assets/_Project/UI/` 폴더와 같다.
수치는 실제 설정 파일 값이다 — 경기 규칙 `UnityClient/Assets/_Project/Core/Data/MatchRuleConfig.asset`, 스킬 `SpellDefinition` SO, 레이팅 · 매칭은 서버 관리자 설정(`Backend/wow_server.py` 기본값).
규칙의 근거와 자세한 설명은 [`Spellbound_VR_Master_Prompt_v6.0.md`](../../Spellbound_VR_Master_Prompt_v6.0.md)(이하 "마스터 프롬프트")를 따른다.

---

## 1. 한눈에 보기

```text
C01 로그인 ─┬─ 이메일 로그인 / 회원가입 / Google 기기 로그인 / 게스트 / 데모 계정
            └─ 서버 없이 시작 (오프라인 봇 연습)
                 │
C02 로비 ───────┼─ 준비: C09 마법서(덱 8장) · 튜토리얼 · C04 설정 · C03 마이페이지
                 ├─ 소셜: C05 친구 · C07 우편함 · C08 랭킹
                 ├─ 게임 종료
                 │
                 ├─ 랭킹전 ──── C09 덱 선택(대전 준비) ── C10 매칭 대기 (15초 안에 사람이 없으면 봇)
                 ├─ 봇 연습전 ── C09 덱 선택(대전 준비) ──┐
                 ├─ 친선전 ──── C06 친선전 룸 (코드 · 초대, 빈자리는 봇)
                 ├─ 스킬 테스트(19종 전부, 기록 안 함)
                 ↓
C11 카운트다운 (3초) ── 여기서 전투 시작 (기다리는 동안 "취소하고 로비로")
                 ↓
C12 전투 (HUD) ── 상대 마법사의 HP를 0으로 만들면 승리 · 경기 메뉴(왼손 메뉴 제스처 / ☰ / Esc): 계속 · 기권
                 ↓
C13 결과 ── 전적 저장 · 레이팅 ── 다시 대전 / 로비로 (씬을 다시 불러와 전장을 비운다) / 게임 종료
```

조작: 메뉴는 **오른손 레이로 가리키고 엄지 · 검지 핀치**(컨트롤러는 트리거, PC는 마우스). 입력칸을 고르면 VR 화면 키보드가 뜬다. 전투에 들어가면 메뉴 레이는 꺼지고 오른손 포인팅은 조준에만 쓴다.

## 2. 접속 (C01 로그인 · 회원가입)

| 방법 | 내용 |
| --- | --- |
| 이메일 로그인 | 이메일 + 비밀번호 6자 이상. "비밀번호를 잊으셨나요?" = 재설정 요청 (메일 서버가 없어 관리자 콘솔 기록으로 남는다) |
| 회원가입 | 닉네임(2~12자, 한글 · 영문 · 숫자 · _, 중복 확인) · 이메일 · 비밀번호 + 확인 · 필수 약관 동의. 비밀번호 강도 막대 표시 |
| Google | **기기 로그인** — 카드에 `google.com/device` 주소 · 코드 · 남은 시간이 뜬다. 휴대폰 · PC 브라우저에서 코드를 넣고 계정을 고르면 자동으로 들어간다 (처음이면 계정 자동 생성) |
| 게스트 | 이름만 넣고(비우면 자동 이름) 바로 입장 |
| 데모 계정 | `demo@wow.dev` / `demo1234` |
| 서버 없이 시작 | 오프라인 모드 — 봇 연습전만, 전적 저장 없음 |

- Quest에서는 카드 아래 **주소 변경**으로 서버 PC의 IP(예: `http://192.168.0.10:8080`)를 넣는다.
- 한 번 로그인하면 토큰이 남아, 다음 실행 때 바로 로비로 들어간다.

## 3. 로비와 준비 (C02 · C03 · C04 · C05 · C07 · C08 · C09 · 튜토리얼)

| 화면 | 할 일 |
| --- | --- |
| **C09 마법서** | 19종 중 **8장** 덱 편성 (중복 불가, **고위력 0~2장**). 덱 순서 = 전투 HUD 슬롯 1~8 = PC 숫자키 1~8. 저장하지 않고 나가면 확인 창 |
| **튜토리얼** | 손동작 5단계(핀치 그리기 → 주먹 → 포인팅 → 손바닥 취소 → 왼손 이동) + PC 키, "연습 시작" = 스킬 테스트 봇전 |
| **C04 환경설정** | 카메라 감도 · 비네팅 · 스냅 이동 / 효과음 · 배경음 · 공간 음향 / 인식 민감도 · 포인팅 유지 · 햅틱 / 자막 · UI 크게 · 색약 모드 (이 기기에 저장) |
| **C03 마이페이지** | 프로필 · 등급 · 승률, 최근 승패, 평균 플레이 시간 · 시전 횟수, 전적 목록, 비밀번호 변경 |
| **C05 친구** | 친구 요청 · 수락 · 거절 · 삭제, 접속 상태 |
| **C07 우편함** | 공지 · 친구 요청 · 친선전 초대(바로 참가) · 시스템 메시지. 보상 · 아이템은 없다 |
| **C08 랭킹** | 랭킹전 레이팅 순위 (친선전 · 봇전 제외) |

**덱이 없거나 규칙에 맞지 않으면 대전 버튼이 막힌다** — 먼저 C09에서 8장을 저장한다.

## 4. 대전 시작 — 모드 4가지

| 모드 | 들어가는 길 | 상대 | 기록 |
| --- | --- | --- | --- |
| **랭킹전** | 로비 → 랭킹전 매칭 → C09 덱 선택 → C10 대기 | 사람. **15초**(서버 설정 `matchmaking.bot_timeout`) 안에 못 찾으면 봇 | 전적 + **레이팅 승 +16 / 패 −16** |
| **친선전** | 로비 → 친선전 → C06 방 만들기 / 코드 참가 / 우편 초대 수락 | 친구. 빈자리는 방장이 봇으로 채울 수 있음 | 전적만 (레이팅 없음) |
| **봇 연습전** | 로비 → 봇 연습전 → C09 덱 선택 → 이 덱으로 시작 | 헤드셋(이 기기) 안의 봇 | 전적만 (오프라인이면 없음) |
| **스킬 테스트** | 로비 오른쪽 아래 → 시작 / 튜토리얼 → 연습 시작 | 봇 | 기록하지 않음. **덱 밖의 룬도 바로 시전, 쿨타임 · 횟수 제한 없음** |

- 등급(칭호): 입문자 < 900 ≤ 견습 마법사 < 1100 ≤ 숙련 마법사 < 1300 ≤ 마법사 < 1500 ≤ 대마법사.
- **덱 선택(대전 준비):** 랭킹전 · 봇 연습전을 누르면 C09가 "대전 준비" 모드로 열린다. 덱을 바꾸면 **이 덱으로 시작**이 저장한 뒤 시작한다.
- **어디서 경기하나:** 봇 연습전 · 스킬 테스트는 항상 헤드셋(이 기기) 안에서. 랭킹전 · 친선전은 `FusionClient` 빌드면 PC 게임 서버, `LocalVsBot` 빌드(★ VR 전체 흐름 APK · 에디터 기본)면 이 기기의 봇이 상대다 — 레이팅 · 전적은 그대로 저장된다.
  PC 게임 서버에 25초 안에 붙지 못하면 알림과 함께 로비로 돌아간다.

## 5. 카운트다운 (C11)

- 양쪽 마법사 · 이름 · 등급, 내 덱 8장(상대 덱은 ?로 가림), **3 · 2 · 1 · START!**
- 이 화면이 열리는 순간 실제 경기를 시작한다. 카운트다운 동안 AFK 타이머는 멈춘다.
- "두 손이 잘 보이도록 앞으로 내밀어 주세요" — 핸드트래킹 준비.

## 6. 전투 (C12)

### 6.1 목표와 전장

- **상대 마법사의 HP(1000)를 0으로 만들면 승리.** 타워 · 넥서스는 승패 조건이 아니라, 무너뜨리면 유리해지는 **방어 계층**이다.
- 전장은 좌(L) · 중(C) · 우(R) **3레인**. 양쪽 끝에 각자의 발판(Commander), 그 앞에 넥서스, 그 앞에 타워.

```text
   [상대 발판  L | C | R]
        [상대 넥서스 4000]
        [상대 타워   3000]
   ───── 전장 3레인 ─────
        [내 타워     3000]
        [내 넥서스   4000]
   [내 발판    L | C | R]
```

### 6.2 조작 — 오른손 = 마법, 왼손 = 이동

| 단계 | 손동작 (Quest) | PC 테스트 키 |
| --- | --- | --- |
| ① 룬 그리기 | 오른손 엄지 · 검지 **핀치한 채** 허공에 룬. 여러 획이면 뗐다가 다시 집어 이어 그린다 | 마우스 왼쪽 드래그 |
| ② 인식 · 준비 | **주먹** — 덱에서 쓸 수 있는 슬롯(Ready)만 비교해 가장 닮은 룬으로 확정. 애매하면 "다시 그려 주세요" | `F` |
| ③ 조준 · 시전 | **검지로 가리키기** — 레인(· 깊이)을 가리킨 채 **2초** 유지하면 시전 확정 | `G` + 마우스 |
| 즉시 시전 | 자기 · 타워 · 전역 스킬(S08 · S09 · S10 · H01 · H04)은 ②에서 바로 나간다 | `F` |
| 취소 | 룬 준비 · 조준 중 **손바닥을 펴면** 취소 (쿨타임 소모 없음). 5초 동안 아무것도 안 하면 자동 취소 | `X` / 우클릭 |
| 이동 | **왼손을 펴고 좌 · 우로 휘두르면** 한 칸 이동 (0.35초 간격, 짧은 순간 이동 + 비네팅) | `A` / `D` |
| 슬롯 바로 시전 | — | 숫자키 `1`~`8` |

조준 종류: 열 지정(투사체 · 빔) / 열 + 깊이(파이어볼 · 독 장판 · 번개 · 분노 등) / 소환 라인 / 설치 구역(내 타워 앞, 타워가 없으면 넥서스 앞).

### 6.3 스킬 · 슬롯 규칙

- 덱 8장은 경기 내내 **같은 슬롯(2줄 × 4칸)에 고정**. HUD에 발동 마법진 · 원형 쿨타임 · 번호가 보인다.
- 쿨타임: **일반 5초 · 고위력 20초**. 서버가 시전을 확정한 순간부터 돈다. 취소 · 거절된 시전은 소모하지 않는다.
- 고위력은 **스킬마다 게임당 3회** — 다 쓰면 슬롯이 "소진"(Exhausted). 남은 횟수는 슬롯에 표시.
- 슬롯 상태: Ready(쓸 수 있음) / 쿨타임 / 소진 / 비활성(예: 내 타워가 무너지면 S09 타워 버프).
- 19종의 효과 · 수치는 마스터 프롬프트 §14.3, 룬 모양은 C09 마법서의 "그리는 룬".

### 6.4 미니언 웨이브

- 경기 시작 **5초 뒤 첫 웨이브, 이후 15초마다** 양 진영에서 **레인마다 근접 1 + 원거리 1** 출발 (한 웨이브 6기).
- **3번째 웨이브마다 Brute 1기** 추가 (구조물에 강하고 구조물을 먼저 친다).
- 진영당 동시 생존 **40기** 상한 — 넘으면 웨이브를 건너뛰고 소환 스킬은 거절(쿨타임 소모 없음). 미니언은 최대 90초 산다.

### 6.5 누가 누구를 때리나 (타겟 규칙)

| 공격자 \ 대상 | 상대 플레이어 | 상대 유닛 (지상 · 공중) | 상대 설치물 (터렛 · 소환탑) | 상대 타워 | 상대 넥서스 |
| --- | --- | --- | --- | --- | --- |
| 플레이어 스킬 | ○ | ○ | ○ | ✕ | ✕ |
| 미니언 · 소환수 | 상대 넥서스가 무너진 뒤에만 ○ | ○ | ○ | ○ | 상대 타워가 무너진 뒤 ○ |
| 타워 · 터렛 | ✕ | ○ | ✕ | — | — |

**타워 · 넥서스는 마법으로 부술 수 없다.** 미니언 · 소환수(오크 · 드래곤 · 해골)를 밀어 넣어야 한다. 마법은 상대 마법사 · 유닛 · 설치물에 쓴다.

### 6.6 방어 계층 — 경기가 진행되는 3단계

| 단계 | 내 구조물 상태 | 상대 스킬로 내가 받는 피해 | 내 HP 회복 (10초마다 25) | 상대 유닛이 나를 공격 |
| --- | --- | --- | --- | --- |
| **1. 초반 (수비 단단)** | 타워 ○ · 넥서스 ○ (넥서스는 무적) | **20%** | ○ | ✕ |
| **2. 중반 (타워 붕괴)** | 타워 ✕ · 넥서스 ○ | **100%** | ○ | ✕ |
| **3. 후반 (돌파)** | 타워 ✕ · 넥서스 ✕ | **100%** | ✕ | **○ (회피 불가)** |

- **넥서스 잠금:** 자기 타워가 서 있는 동안 넥서스는 무적이다.
- **진영 공격력 배율** (내 모든 공격에 곱): 1.0 + 상대 타워 파괴 **+0.2** + 상대 넥서스 파괴 **+0.4** + 강화 단계 × 0.15.
- **돌파:** 상대 넥서스가 무너지면 내 유닛이 상대 발판 앞까지 전진해 상대 마법사를 직접 공격한다 (레인과 무관, 피할 수 없음).
- 타워 · 넥서스는 HP 0이 되면 폭발 연출 후 사라지고 돌무더기만 남는다.

### 6.7 5분 강화

- **5:00, 10:00, 15:00 …마다 양쪽 모두** 영구 강화: 공격력 **+15%**, 쿨타임 **−10%** (최소 50%까지).
- HUD 가운데 판의 **POWER UP** 칸이 다음 강화까지 남은 시간이다.

### 6.8 피하기

- 투사체 · 빔 · 낙뢰 · 착탄형 공격은 **왼손 이동으로 레인을 옮기면 피할 수 있다** (도착 · 착탄 · 낙뢰 순간의 위치로 판정). 레이저 빔은 0.5초 예고선, 번개는 0.45초 먹구름 예고가 상대에게도 보인다.
- 장판(독 · 분노)은 매 틱 판정 — 벗어나면 그만 맞는다. 미니언 · 소환수의 돌파 공격은 피할 수 없다.
- 방어 수단: S08 방어 쉴드(흡수 180), H04 반사 결계(9초간 스킬 피해 무효 + 100% 반사).

### 6.9 끝나는 조건

| 조건 | 결과 |
| --- | --- |
| 내 HP 0 | 패배 (리스폰 없음, 구조물 상태와 무관) |
| 양쪽이 같은 틱에 HP 0 | 무승부 |
| 사람 플레이어 **30초 무활동** (20초에 경고) | 기권패. 활동 = 룬 그리기 시작 · 시전 성공 · 왼손 이동 (고개 움직임은 아님) |
| 사람 플레이어 연결 끊김 | 패배 |
| PC 서버 오류로 세션 종료 | 무효 (전적 기록 안 함) |
| **경기 메뉴 → 기권** | 패배 (연결 끊김과 같은 규칙으로 처리, 전적에 패배로 저장, 결과 이유 "경기 중 기권했습니다") |

**경기 메뉴:** 왼손 메뉴 제스처(손바닥을 얼굴 쪽으로 보이고 엄지 · 검지 집기) · 왼쪽 컨트롤러 ☰ · PC는 Esc. 1:1 실시간이라 **경기는 멈추지 않고**, 메뉴가 열린 동안 룬 그리기 · 이동만 멈춘다 (오래 열어 두면 AFK 규칙이 적용된다).

**제한 시간은 없다.** 5분 강화로 양쪽 화력이 계속 올라가므로 경기는 결국 끝난다.

### 6.10 전투 HUD (C12) 읽는 법

- 위: 나(보라) · 상대(빨강) HP 막대, 가운데 **TIME · STAGE · POWER UP**.
- 둘째 줄: 내 방어 / 상대 방어 — 타워 · 넥서스 알약(청록 = 서 있음, 빨강 = 무너짐), 받는 피해 20% / 100%, 회복 여부, 공격 배율.
- 셋째 줄: 다음 웨이브까지 초(+브루트) · 내 위치 L / C / R · 상태 효과(쉴드 남은 초 · 반사 결계 · 집중).
- 슬롯 8칸: 발동 마법진, 원형 쿨타임 가림 + 남은 초, 번호, READY / 쿨타임 / 소진 / 비활성, 고위력은 호박색 테두리 + 남은 횟수.
- 가운데 큰 글자: 카운트다운 · FIGHT! · 결과. 그 아래 시전 거절 사유 · 구조물 파괴 · 돌파 · 강화 알림, AFK 경고.

## 7. 결과 (C13)

- **VICTORY / DEFEATED / DRAW**, 상대 · 모드 · 끝난 이유.
- 랭킹전: 레이팅 변화(+16 / −16)와 새 레이팅 · 등급. 그 밖의 모드: 전적 저장 상태.
- 기록 4칸: 입힌 피해 · 시전 횟수 · 받은 피해 · 플레이 시간.
- **다시 대전** — 랭킹전은 다시 매칭(C10), 친선전은 룸(C06)으로, 봇 · 스킬 테스트는 같은 상대로 바로(C11). **로비로** — C02. **게임 종료** — 확인 후 앱 종료.
- 스킬 테스트는 "스킬 테스트는 전적에 기록하지 않습니다"로 표시되고 서버에 남지 않는다.
- 어느 쪽이든 씬을 다시 불러와 전장(유닛 · 구조물 · 이펙트)을 깨끗이 비운 뒤 다음 화면을 연다.

## 10. 값의 기준

경기 규칙 수치는 **설정 파일이 기준**이고, 이 문서 · 마스터 프롬프트는 같은 값을 적는다 (2026-10-25 통일: 웨이브 5초 + 15초마다 레인당 근접 1 · 원거리 1, 조준 2초, 타워 초당 1회 · HP 3000, 넥서스 HP 4000, 봇 대체 대기 15초 / 30초).
값을 바꿀 때는 `MatchRuleConfig.asset`(경기 규칙) · `SpellDefinition` SO(스킬) · 서버 관리자 설정(레이팅 · 매칭)을 고치고, 마스터 프롬프트 §3.3 · §14.3 · §15 · §18 · §19 와 이 문서를 같이 고친다.
